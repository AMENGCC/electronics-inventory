整体导出

将全部物料资料、库存、安全库存、存放位置、供应商、历史流水、项目、BOM 与自动编号保存为一个 JSON 文件。

整体导入

导出带中文表头的清单，可在 Excel 中查看和统计。CSV 不包含历史流水，设备整体迁移请使用 JSON 文件。

数据保存在你的 NAS 上
